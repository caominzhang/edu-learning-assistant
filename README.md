# EDU 学习助手

版本：0.2.0-preview.1 · 数据库结构：schema-1 · 文档：rev-1（2026-11-01）

面向家庭的本地学习记录工具。共用一套核心代码，提供群晖 Docker 部署方式及 Windows 独立桌面启动器。当前是预览源码，尚未发布到公开仓库。

## 已实现

- 手动录入各科成绩、满分、排名、参与人数，汇总得分率，导出 CSV。
- 上传 JPG/PNG/WEBP 图片，保存老师原话及表扬记录。
- 可选本地 Tesseract OCR，按配置姓名进行匹配，人工确认出现或未出现。
- Windows 首次填写姓名，启动本机服务并打开浏览器；不依赖群晖。
- 群晖 Compose 配置及密码访问；不内置任何真实学生数据。

## 尚未实现

群晖 Chat 接入、微信/QQ 自动采集、手写成绩表自动结构化、错题本、在线 AI、拖入及剪贴板粘贴、托盘及开机启动、应用内备份恢复、完整记录编辑删除。

Windows EXE 构建流程已经提供，但本交付没有附带已构建或实机验证的 EXE，也没有安装器。Windows 包默认不包含 Tesseract 引擎和中文字库；没有它们仍可录入成绩、上传图片、人工确认，OCR 会显示未运行。实现完整免配置 OCR 后才能作为面向普通家庭的正式版。

## 识别原则

疑似匹配需要人工确认；未识别到不代表名字不存在。没有出现在表扬名单中不构成负面评价。本项目不会用缺席记录给孩子扣分。不承诺提分或替代教师判断。

## 开发运行

Python 3.10 以上；执行 `python -m pip install -r requirements.txt` 后运行 `python app.py`。默认入口 http://127.0.0.1:8765，默认示例姓名可通过 TRACKER_STUDENT 修改。数据默认位于程序旁的 data 目录。Windows 用户应使用 windows_launcher.py，以便将数据保存到个人用户目录。

开发者运行 `python smoke_test.py` 可检查共享核心的鉴权、录入、确认、导出与校验。

## 隐私和许可

真实班级截图可能包含其他未成年人信息，请仅在自己的私有实例使用。程序不调用在线识别服务。群晖认证使用 HTTP Basic；通过 HTTPS 反向代理或 VPN 访问，不要把应用端口直接开放公网。它是家庭单用户程序，没有多家庭隔离。
