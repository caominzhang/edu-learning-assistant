# 开源发布清单

当前为双版本预览源码。已推送到 GitHub；尚未生成或发布正式 Windows 安装包。

- MIT 是本整理版的默认源码许可；原始代码所有权及第三方代码授权仍需在发布前核实。
- 新建仓库只导入此整理目录；不要连同旧归档、data、真实截图、.env、数据库和缓存提交。
- 若导入现有仓库，须额外检查完整提交历史，泄露过的密钥要更换；本次没有可访问的历史仓库，因此未完成历史审查。
- 发布演示只用虚构姓名、模拟分数和自行制作的截图。
- 在真实群晖验证镜像构建、登录、手机上传、重启和备份恢复。
- 在干净Windows机器验证运行包不依赖Python、首次配置、数据持久化、升级、端口占用及退出。
- 完成 Windows OCR 引擎及中文字库随包分发和依赖许可核对，或在发布页明确基础版不含OCR。
- 验证跨版本迁移，整理第三方许可与版本固定策略。
- 将验证通过的版本打 tag，分别上传群晖部署源码包和Windows运行包，附发布说明与已知限制。

后续开发顺序：完整记录编辑删除 → 备份恢复界面 → Windows免配置OCR → 截图粘贴 → 群晖Chat入口 → 安装器和托盘。每项区分已实现、已测试与已部署。
